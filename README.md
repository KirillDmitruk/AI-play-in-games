# AI Snake 2.0

Наблюдение за Gemini, играющей в змейку. Модель сохранена: **gemini-2.5-flash**.
Игра не меняет веса модели. Необязательная память передаёт краткие выводы между партиями.

## Быстрый запуск — Windows / PowerShell

Распакуйте архив в отдельную папку и откройте её в PyCharm. Не смешивайте новые файлы со старой версией. Если переносите изменения в существующий проект, замените файлы и добавьте новые модули из архива.

В терминале из папки, где находится `main.py`:

```powershell
uv sync --frozen
$env:GEMINI_API_KEY = "ВАШ_КЛЮЧ"
uv run main.py
```

Если `uv` не установлен, используйте Python 3.11 или 3.12:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:GEMINI_API_KEY = "ВАШ_КЛЮЧ"
.\.venv\Scripts\python.exe main.py
```

При запуске зелёной кнопкой PyCharm: **Run → Edit Configurations → main.py → Environment variables**, добавьте `GEMINI_API_KEY` со значением ключа. Выберите интерпретатор `.venv`.

Ключ не вставляется в код. `GOOGLE_API_KEY`, если она тоже задана, имеет приоритет, как в SDK Google. `.env` автоматически не загружается. Файл `.env.example` — только пояснение. Переменная, установленная через `$env:`, действует в текущем терминале.

Сначала можно проверить окно без ключа и без расходов:

```powershell
uv run main.py --manual
```

Старый вход в ручную игру также работает: `uv run game.py`.

## Управление

| Действие | Клавиша / кнопка |
| --- | --- |
| Пауза / продолжение | Space |
| Один игровой шаг с сохранением паузы | N |
| Новая партия | R |
| Повторить запрос после ошибки или отвергнутого плана | C |
| Увеличить / уменьшить скорость исполнения | + / - |
| Закрыть окно и прекратить ожидание запроса | Esc |
| Управление вручную | WASD или стрелки |

Пауза не отменяет уже отправленный запрос: ответ сохранится, но змейка не двинется. При N может понадобиться дождаться нового плана; после этого выполнится ровно один шаг. Пока Gemini думает, поле не меняется, а окно продолжает обрабатывать события и показывать время ожидания.

R и закрытие окна останавливают локальный процесс запроса. Это не гарантирует отмену обработки на стороне Google: возможный расход такого запроса учитывается как неизвестный. Ответ отменённого процесса не может попасть в новую партию.

## Что изменено

- Единые правила `SnakeGame` для человека и Gemini; импорт модулей не открывает окно и не создаёт API-клиент.
- Вызов модели выполняется в отдельном процессе с общим ограничением времени; все операции Pygame остаются в главном потоке.
- Вместо `interactions.create` используется `models.generate_content` того же SDK и той же модели. Это позволяет явно задать `thinking_budget=0`, предел ответа и JSON-схему.
- План содержит от 1 до 3 направлений по умолчанию. Проверяются структура, длина, допустимые значения и завершённость ответа. При съедании яблока остаток плана удаляется.
- Неверный ответ не приводит к движению по инерции. Запрещённый разворот останавливает выполнение плана, записывается в журнал и показывает ошибку.
- Игра не спасает модель от разрешённого правилами, но смертельного хода: столкновение завершает партию. Скрытого алгоритма, заменяющего решения Gemini, нет.
- Новое яблоко выбирается из свободных клеток после обновления тела. Полностью заполненное поле — победа. На шаге без роста разрешён вход в клетку уходящего хвоста.
- Сбой API оставляет окно открытым. Временные сетевые ошибки, 429/5xx и ошибки формата получают ограниченные повторы с задержкой. Скрытые повторы SDK отключены.
- Есть лимиты запросов, шагов, шагов без еды и известных токенов.
- Записываются состояния, запрошенные и применённые действия, причины окончания, статистика запросов и доступное число токенов. Ключи и сырые SDK-ошибки не записываются.
- Панель показывает счёт, лучший результат текущего запуска, seed, план на поле, время ожидания, токены и ошибки.

## Настройки

Все значения находятся в `settings.json`.

| Параметр | По умолчанию | Назначение |
| --- | ---: | --- |
| `plan_length` | 3 | 1–5 ходов на один запрос; 1 удобен для сравнения с прежней версией |
| `thinking_budget` | 0 | Отключает рассуждение Gemini 2.5 Flash; можно проверить бюджет от 128 |
| `max_output_tokens` | 128 | Ограничение генерации; при ненулевом thinking должно быть больше бюджета рассуждения |
| `timeout_seconds` | 30 | Предельное ожидание одного рабочего процесса, включая запуск |
| `max_retries` | 2 | До двух дополнительных попыток для одного плана |
| `retry_delay_seconds` | 1 | Начальная задержка повтора; удваивается при следующей ошибке |
| `steps_per_second` | 5 | Скорость исполнения готового плана, не частота API-запросов |
| `max_steps` | 2000 | Максимум шагов партии |
| `max_idle_steps` | 200 | Завершение партии после стольких шагов подряд без еды |
| `max_episode_requests` | 100 | Предел запросов партии, включая повторы и разбор |
| `max_session_requests` | 200 | Предел запросов за весь запуск, не сбрасывается клавишей R |
| `max_session_tokens` | 50000 | Запрет новых запросов после достижения известного расхода |
| `memory` | false | Загружать и обновлять память между партиями |

Лимит токенов — порог по данным уже полученных ответов, а не точная финансовая квота. Один ответ может вывести расход выше порога; ошибка или отмена иногда не возвращает usage. Повторы тоже могут тарифицироваться. Счётчик запросов увеличивается перед ожиданием ответа. Уже оплаченный план может быть исполнен после достижения токенного порога; новые запросы не отправляются. Пределы токенов и запросов сбрасываются только при новом запуске приложения.

Токены рассуждения показываются отдельно; денежная стоимость не рассчитывается. Отключение рассуждения и пакет ходов не гарантируют прежнее качество стратегии — сравнивайте результаты.

## Память между играми

```powershell
uv run main.py --memory
```

После естественного завершения партии выполняется до одного дополнительного запроса на краткий разбор последних восьми переходов, если общий бюджет позволяет. При закрытии или R разбор не запускается. Разбор использует ту же модель, до 256 выходных токенов при стандартных настройках и те же пределы запросов/расхода. Неудачный разбор автоматически не повторяется.

В `logs/memory.json` сохраняется не более пяти кратких выводов. Они передаются в следующие планы. Для чистого сравнения запустите без памяти или удалите этот файл. Выводы могут оказаться ошибочными; улучшение результатов нужно проверять. Это память в контексте, а не обучение весов и не reinforcement learning.

## Запись и повтор

Каждая партия автоматически записывается в `logs/*.jsonl`. Имя текущего файла показано под полем. Записи сбрасываются на диск после каждого события. При аварии незавершённую последнюю строку проигрыватель пропускает с предупреждением.

```powershell
uv run main.py --replay logs/ИМЯ_ЗАПИСИ.jsonl
```

Ключ не требуется, API не вызывается. Space — пауза, N / стрелка вправо — следующий кадр, стрелка влево — предыдущий, R — начало. Воспроизводятся сохранённые состояния; паузы сети в реальном времени не повторяются.

Для сравнения нескольких запусков:

```powershell
uv run main.py --seed 42
```

Фиксированный seed задаёт одинаковую последовательность генератора случайных чисел. Клавиша R повторяет этот seed. Если траектории отличаются, расположение последующих яблок тоже может отличаться из-за разных занятых клеток. Без `--seed` каждая новая партия получает случайный seed. JSONL хранит seed и использованные настройки.

## Структура

- `main.py` — аргументы запуска.
- `game.py` — игровое состояние и `step(action)`.
- `agent.py` — запрос к Gemini, схемы, проверка ответа и usage.
- `worker.py` — запуск, опрос, тайм-аут и отмена процесса запроса.
- `controller.py` — планы, пауза, бюджеты, повторы, переход между партиями.
- `app.py` — отрисовка и события Pygame.
- `records.py` — запись, воспроизведение и локальные выводы.
- `settings.py`, `settings.json` — настройки и проверка их значений.
- `tests/` — проверки без реальных API-запросов.

## Проверки

```powershell
uv run python -m unittest discover -s tests -v
```

Тесты используют виртуальный видеодрайвер, не открывают окно и не расходуют токены. Результаты выполненных проверок находятся в `TEST_REPORT.md`.

## Если запуск не удался

- **Нет ключа:** окно остаётся открытым с подсказкой. Задайте переменную в том окружении, из которого запускаете Python, и перезапустите приложение.
- **401/403:** проверьте действительность ключа, доступ и настройки Google AI Studio. Новый ключ не нужно отправлять в чат.
- **429/503:** дождитесь ограниченных повторов; после их исчерпания можно нажать C. Общие лимиты остаются действующими.
- **`ImportError` и SOCKS-прокси:** это дополнительная зависимость прокси. Для uv: `uv run --with socksio main.py`. Для обычного pip: `python -m pip install socksio`. Без SOCKS-прокси пакет не нужен.
- **Нет доступа к каталогу записей:** укажите доступную папку через `--logs ПУТЬ`. Ошибка записи приостанавливает игру, чтобы не терять результаты незаметно.
